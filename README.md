# mikeandbones

Skull and Bones Solo-PvE-Guide für Year 3 Season 1 "Shattered Seas".

Statische Website, gehostet via GitHub Pages. Deutsche Erklärungen, englische Ingame-Begriffe.

## Lokales Testen

```
python -m http.server 8000
```

Dann http://localhost:8000 öffnen.

## Tech

- Vanilla HTML / CSS / JavaScript (ES Modules)
- Kein Build-Step, kein Framework
- Tooltips: Floating UI
- Inhalte in `/data/*.json`, Quellen in `/sources/`
